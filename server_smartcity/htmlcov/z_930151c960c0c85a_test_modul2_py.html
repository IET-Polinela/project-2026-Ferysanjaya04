169 def test_PRIV_03_tidak_bisa_baca_draf_orang_lain(self): 

170 """ 

171 [PRIV-03] Warga A mencoba membaca detail data laporan berstatus DRAFT 

172 milik Warga B melalui parameter ID API. 

173 

174 SKENARIO: 

175 Warga A mengakses endpoint detail laporan (/api/report/<id>/) untuk 

176 laporan berstatus DRAFT milik Warga B. 

177 

178 HASIL YANG DIHARAPKAN: 

179 Sistem menyembunyikan keberadaan draf tersebut dan mengembalikan 

180 status HTTP 404 Not Found demi keamanan. 

181 

182 PENJELASAN TEKNIS: 

183 Pada get_queryset(), ketika tidak ada parameter tab yang spesifik, 

184 queryset difilter sehingga DRAFT milik orang lain tidak masuk ke 

185 dalam hasil query. Sehingga get_object() akan melempar Http404. 

186 Ini merupakan teknik keamanan "security through obscurity" — sistem 

187 berpura-pura data tidak ada, bukan mengatakan "akses ditolak". 

188 """ 

189 self.client.force_authenticate(user=self.warga_a) 

190 

191 response = self.client.get(f'/api/report/{self.draft_milik_b.pk}/') 

192 

193 self.assertEqual(response.status_code, status.HTTP_404_NOT_FOUND) 

194
